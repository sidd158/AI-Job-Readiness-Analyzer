JOB READINESS ANALYZER
Keep app.py, style.css and requirements.txt in the same folder.

Install:
python -m pip install -r requirements.txt

Run:
python -m streamlit run app.py

Use:
1. Select a target role.
2. Upload a text-based PDF resume.
3. Click Analyze Resume.
4. Review readiness, role match, radar chart, skill gaps and action plan.
5. Download the CSV.

Scanned/image-only PDFs need OCR and are not supported by this simple parser.
